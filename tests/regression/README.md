# Suíte de regressão

Suíte macro, organizada por **módulo e área** (ex.: `vendas/venda-rapida/`). Reúne os fluxos mais críticos de cada módulo. Os módulos e áreas vêm do [mapa do sistema](../../docs/mapa-do-sistema.md). Toda spec aqui deve usar a tag `@regression`.

Veja a convenção completa em [`../README.md`](../README.md).
